# Utilizando o Markdown!
## Nível Dois de Título
### Nível Três de Título

Markdown é uma linguagem de marcação mais simples que o HTML, muito utilizado nos repositórios com a finalidade de detalhar aspectos do código.

Para marcar textos em **negrito** basta utilizar dois asteriscos delimitando o texto. 

Para marcar textos em *itálico* basta utilizar um asterisco delimitando o texto.
